Under the hood

The Messages API keeps no conversation on its side. So Claude Code sends the whole conversation again on every turn: your prompts, each tool_result (files, command output), CLAUDE.md and the system prompt.

02 · How a mod plugs in

A mod is a link in the chain

Claude Code raises an event at each step of a turn. Every mod that hooks the event gets it in turn, and can pass it on, change it, refuse it or answer it.

The rules
    
      
  • A hook is on(event, matcher?, ($, e, next) => …). $ is Claude Code's API, e the event, next the rest of the chain.
    • 
      
  • A hook gets 10 s of running time. A hook that throws or runs over is skipped, and for a masking hook that would mean the text goes out unmasked. So every masking hook has a .catch.

05 · Unmasking a stream

    
Replies arrive in pieces

    
The model streams its answer a few characters at a time. A placeholder can be cut in half between two pieces. Press Next piece and watch the mod hold back the half until it is complete.

    

      

        
From the API

        
Held back

        
Your screen

      

      

    

    

      
StreamUnmasker, in hooks/masker.ts


function holdFrom(buf) {
  const i = buf.lastIndexOf('<<')
  // a tail that could still become a placeholder waits
  if (i >= 0 && buf.length - i <= 80 && PARTIAL.test(buf.slice(i))) return i
  if (buf.endsWith('<')) return buf.length - 1
  return buf.length
}

      
Why it matters
Without the hold-back, you would see a raw placeholder flash on screen, and a placeholder cut in two would never be restored. The hook is turn.step, an async generator: it yields each piece of the stream to the screen after unmasking it.

08 · Finding the names · new in 0.6

    
A list is exact. A local model catches the rest.

    
detection
      

        
        
        
      

    

    

    

      
The call to the NER server, on localhost

        

      
What NER is
Named entity recognition: a small model trained to find companies, people and places in text. It runs on your machine (spaCy or GLiNER) in tools/ner-server. A name it finds once stays masked for the rest of the session. If the server doesn't answer, the session is blocked.

      
Measured with spaCy en_core_web_lg on a 2-core cloud VM, no GPU.

The test, in tools/reid-test

        
    
          
  • Haiku and Sonnet were shown masked texts about 5 well-known customers and asked who is behind each placeholder, with a confidence.
    • 
          
  • From context alone (the city, the goods, the products), they named 3 to 4 of the 5.
    • 
          
  • Masking brands and addresses as aliases lowered their confidence but didn't stop them: "a distribution centre in Jiaxing" was enough.
    • 
          
  • Small, ordinary customers leave little to guess from. That is most of our data.
    •

12 · Get it

    
Running in three steps

    

      
1InstallClaude Code 2.1.296 or newer
        
/plugin install customer-mask \
  --marketplace majidkabir/customer-mask

      
2Tell it your customers.claude/customer-mask.json
        
{
  "customers": [{
    "name": "Acme Freight A/S",
    "hint": "Danish freight forwarder"
  }],
  "patterns": [{ "label": "SHIPMENT",
    "regex": "\\bSHP\\d{8}\\b" }],
  "detection": "both"
}

      
3Optional: NER, then checktype /customer-mask in a session
        
pip install spacy
python -m spacy download en_core_web_lg
python3 tools/ner-server/server.py \
  --backend spacy

    

    
For the whole team
Managed settings install it on every machine from an admin-only folder, load it before any mod a user adds, and point every session at one customer list that a scheduled job builds from the CRM export (tools/build-customer-list.mjs). Docs, tests and open questions: github.com/majidkabir/customer-mask
